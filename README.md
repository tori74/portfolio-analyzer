# Portfolio Analyzer

Веб-инструмент для анализа инвестиционного портфеля частного инвестора на Мосбирже.

Инвестор вставляет свой портфель текстом (любой формат — позиции с тикерами и объёмами), а сервис возвращает структурированный отчёт: распределение по классам активов, концентрационные риски, оценка диверсификации, корреляции, метрики доходности и риска.

Используется учениками онлайн-клуба инвестиций «Семья» в ежедневной работе.

## Что умеет

- Парсинг свободного текстового ввода портфеля (тикер + кол-во + средняя цена)
- Подтягивает живые данные с Мосбиржи (котировки, лотность, метаданные облигаций)
- Подтягивает ставки ЦБ для дисконтирования
- Считает доходности, риск, корреляции, диверсификацию
- Выдаёт визуализацию: круговая диаграмма по классам активов, столбцы по эмитентам
- Сравнивает портфель с модельными ориентирами клуба

## Стек

- **Frontend** (этот репо): чистый HTML + CSS + JS, без фреймворков. Manrope шрифт. Mobile-first дизайн.
- **Backend** (приватный): FastAPI + Python, интеграция с Мосбиржей, ЦБ РФ, базой эмитентов, движком анализа.

## Контекст

Реальный коммерческий продукт, используется ежедневно учениками клуба «Семья». Не учебный проект.

Frontend публичен — его можно открыть и посмотреть UX/код. Backend остаётся приватным, потому что содержит бизнес-логику клуба и интеграции.
